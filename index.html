Sia Linux packages

Official Debian and Ubuntu packages for the Sia daemons, signed and served from linux.sia.tech.

$ curl -fsSL https://linux.sia.tech/install.sh | sh

Installs hostd. Pass a different daemon with sh -s -- renterd. The script adds the apt repository, installs the package, and stops there. Nothing is enabled or started until you configure it.

Supported releases

  • Debian bullseye, bookworm, trixie
  • Ubuntu jammy, noble, questing

After installing

$ sudo hostd config $ sudo systemctl enable --now hostd

Each daemon writes its own config under /etc. The service is not enabled by the package, so enable it once the daemon is configured.
